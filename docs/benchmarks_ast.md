# AST Benchmarks

The AST benchmark compares structural search through `tg run` with the official
`sg` (ast-grep) CLI. Correctness and timing are separate checks.

## Corpus and parity

Use the deterministic corpus generated by the benchmark script and record its
file count, language mix, source size, and patterns in the output artifact.
Compare normalized structural matches before making a performance claim. The
parity runner exercises Python, JavaScript, TypeScript, and Rust cases; parser
coverage does not imply identical support for every language or pattern.

## How to Run

```bash
uv run python benchmarks/run_ast_benchmarks.py --output artifacts/bench_run_ast_benchmarks.json
uv run python benchmarks/run_ast_parity_check.py --output artifacts/ast_parity_report.json
```

Report the actual binary versions, sample count, warmups, medians, and configured
`max_ratio_tg_vs_sg` threshold. Keep cold startup and repeated-query measurements
separate. See [benchmark acceptance rules](benchmarks.md#acceptance-rules).
