# Contributor onboarding

Start with [the getting-started guide](getting-started.md) to try tensor-grep on a small
project. Read [the architecture guide](architecture.md) to understand native routing,
Python orchestration, repository context, sessions, and MCP.

For development setup and validation, follow [CONTRIBUTING.md](https://github.com/oimiragieo/tensor-grep/blob/main/CONTRIBUTING.md).
[AGENTS.md](https://github.com/oimiragieo/tensor-grep/blob/main/AGENTS.md) records the public contribution requirements for humans and coding
assistants, including command registration, compatibility, security review, and release checks.

## Find the right reference

| Task | Reference |
|---|---|
| Install and check platform support | [Installation](installation.md), [support matrix](SUPPORT_MATRIX.md) |
| Understand routing and failure behavior | [Routing policy](routing_policy.md), [contracts](CONTRACTS.md) |
| Use CLI or MCP from another tool | [API reference](harness_api.md), [automation recipes](harness_cookbook.md) |
| Validate a performance change | [Benchmarks](benchmarks.md), [tool comparison](tool_comparison.md) |
| Understand CI or prepare a release | [CI pipeline](CI_PIPELINE.md), [release checklist](RELEASE_CHECKLIST.md) |
| Choose a public contributor skill | [Skill index](https://github.com/oimiragieo/tensor-grep/blob/main/AGENTS.md#skills) |

## Public and private material

The repository includes a small, reviewed set of product and contributor skills. Internal
operating procedures, unpublished research, local configuration, and private workflows belong
in a private skill store. See [the publication policy](https://github.com/oimiragieo/tensor-grep/blob/main/CONTRIBUTING.md#agent-skills-and-private-material).
