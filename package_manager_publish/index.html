    Package Manager Publish Runbook

    This runbook defines repeatable Homebrew and Winget publish/rollback procedures after a successful main release pipeline, with registry parity checks for PyPI and npm.

    GitHub tag releases now publish an autogenerated package-manager-bundle/ asset tree containing: - homebrew-tap/Formula/tensor-grep.rb - winget-pkgs/manifests/o/oimiragieo/tensor-grep/<version>/oimiragieo.tensor-grep.yaml - PUBLISH_INSTRUCTIONS.md - BUNDLE_CHECKSUMS.txt (SHA256 for bundle files)

    The commands below describe maintainer publication procedures, not currently available install channels. npm, Homebrew, and Winget manifests are not yet published to their registries; see installation. Run registry install and rollback checks only after the corresponding package is published.

    Preconditions

    1. CI on main is green, including:
    2. release-readiness
    3. package-manager-readiness
    4. publish-pypi (if publish_pypi=true)
    5. For tag workflows, release-success-gate must be green after the final npm + PyPI parity re-checks.
    6. Version-bearing files are aligned and validated:
    7. pyproject.toml
    8. rust_core/Cargo.toml
    9. npm/package.json
    10. scripts/tensor-grep.rb
    11. scripts/oimiragieo.tensor-grep.yaml
    12. Run: 
      uv run python scripts/validate_release_assets.py
uv run python scripts/prepare_package_manager_release.py --check

    Homebrew Tap Flow

    1. Clone your tap repo: 
      git clone https://github.com/oimiragieo/homebrew-tap.git
cd homebrew-tap
    2. Copy updated formula from tensor-grep: 
      cp /path/to/tensor-grep/scripts/tensor-grep.rb Formula/tensor-grep.rb
ruby -c Formula/tensor-grep.rb
    3. Commit and open PR: 
      git checkout -b release/tensor-grep-vX.Y.Z
git add Formula/tensor-grep.rb
git commit -m "chore(brew): publish tensor-grep vX.Y.Z"
git push origin release/tensor-grep-vX.Y.Z
    4. After merge, smoke-test install: 
      brew update
brew install oimiragieo/tap/tensor-grep
tg --version

    Winget Flow

    1. Fork and clone winget-pkgs: 
      git clone https://github.com/<you>/winget-pkgs.git
cd winget-pkgs
    2. Add/update manifest for oimiragieo.tensor-grep at version X.Y.Z.
    3. Validate locally: 
      winget validate --manifest .\manifests\o\oimiragieo\tensor-grep\X.Y.Z\
    4. Commit and open PR: 
      git checkout -b release/tensor-grep-vX.Y.Z
git add manifests/o/oimiragieo/tensor-grep/X.Y.Z
git commit -m "chore(winget): publish tensor-grep vX.Y.Z"
git push origin release/tensor-grep-vX.Y.Z
    5. After merge, smoke-test: 
      winget install oimiragieo.tensor-grep
tg --version

    Rollback Procedures

    1. Homebrew rollback:
    2. Revert tap formula to previous known-good release.
    3. Run: 
      git revert <tap-formula-commit>
git push origin <rollback-branch>
    4. Merge revert PR.
    5. Ask users to run brew update and reinstall.
    6. Winget rollback:
    7. Submit manifest update PR pointing to prior known-good installer.
    8. Validate rollback client behavior: 
      winget uninstall oimiragieo.tensor-grep
winget install oimiragieo.tensor-grep
tg --version
    9. If needed, submit corrective patch manifest release.
    10. PyPI/GitHub mismatch:
    11. Do not delete production artifacts as primary fix.
    12. Publish a corrective patch release (X.Y.(Z+1)) and re-run parity gates.
    13. npm/GitHub mismatch:
    14. Do not unpublish stable versions as primary rollback.
    15. Publish a corrective patch release (X.Y.(Z+1)) and re-run parity gates.
